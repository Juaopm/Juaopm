## 🚀 Projeto em destaque

### 🎮 MatchTracker+

> Aplicação web em desenvolvimento para registrar partidas de CS2, consultar o histórico e acompanhar estatísticas de desempenho.

- **Objetivo:** facilitar o acompanhamento da evolução e do desempenho dos jogadores.
- **MVP:** cadastro e login, registro de partidas, histórico, estatísticas gerais e leaderboard por maior K/D.
- **Front-end:** React, TypeScript e Tailwind CSS.
- **Colaboração e versionamento:** Git e GitHub.
- **Status:** em desenvolvimento.
